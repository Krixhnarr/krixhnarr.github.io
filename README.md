GitHub user-site for Krixhnarr. Hosts `/.well-known/assetlinks.json`, which
lets the Kerala Market Android app (https://github.com/Krixhnarr/kerala-market)
open without a browser URL bar - Digital Asset Links verification requires
this file at the origin root, and GitHub user pages are the only "root" a
free GitHub account gets without a custom domain.

Also hosts [WildDex](https://krixhnarr.github.io/wilddex/) (`/wilddex/`), an
animal-scanning collection game — see `wilddex/README.md`.
